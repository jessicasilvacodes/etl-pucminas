# Disciplina 'Preparação e Integração de Dados', da pós-graduação em **Ciência de Dados Aplicada à Saúde**, da PucMinas.

### Objetivo do Projeto:
Realizar o processo completo de ETL (Extração, Transformação e Carga), integrando e tratando dados provenientes de diferentes fontes utilizando o Power BI. O foco principal foi garantir a qualidade e a consistência dos dados para análises futuras.

Foram utilizados dados brutos oriundos de diferentes formatos, como:
- Bancos de dados SQL;
- Arquivos CSV;
- Arquivos Excel;
- Dados estruturados extraídos de HTML (tabelas online);

### ETL:

**Extração:** Importação dos dados a partir de diversas fontes diretamente no Power BI.
**Transformação:** Tratamento de valores ausentes e inconsistentes, padronização de formatos (datas, números, textos, etc.), integração de dados em um modelo consolidado.
**Carga:** Organização dos dados tratados em tabelas prontas para análises futuras.
